# 世界描述模型

本章说明约定以哪些方式描述世界，以及现行指令作用于哪些对象：

- [信息、物质、规律与场](信息、物质、规律与场.md)：四个基础概念及可写边界；
- [指令效果框](指令效果框.md)：引用位置以及字形尺寸、方向与时间轴如何成为世界效果；
- [现实状态与外置记忆](现实状态与外置记忆.md)：如何用现实关系保留有限状态。

场类指令分为引力、电磁与流动三族。电磁族按方向性质分成电场和磁场两个指令；加上物质跌落，现行表共有五种基础指令。四种场类指令在执行瞬间改写范围内原子的物理状态，随后由自然规律继续演化。

全部指令条目见[指令参考](../06-符文参考/指令/README.md)。
