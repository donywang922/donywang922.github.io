# 算子组合示例

本页使用印刷记号展示基础算子的常见组合。式中每个大写字母都代表已经存在且最终可追溯到现实的引用。

## 从现实量得到零和一

设 `A` 是有效的量。由于同一个引用不能同时占据两个输入位，先复制出独立引用 `A'`：

```text
A' = 复制(A)
Z  = 差量(A, A')
```

`Z` 的值为零，并保留 `A` 的现实来源；`A` 无结果时，`Z` 也无结果。

若 `A` 非零：

```text
U = 比率(A, A')
```

`U` 是无量纲的一，同样保留 `A` 这一现实来源。

## 相等与次序

对两个已知有效、量纲相同的量 `A`、`B`：

```text
相等     = 判空(差量(A, B))
A不大于B = 判空(超量(A, B))
A大于B   = 非(判空(超量(A, B)))
```

若输入可能无结果，判空会把无结果与默认值一同判为成立，因此应先确认输入来源有效。

## 整数余数

设 `A`、`B` 是有效的无量纲整数且 `B` 为正：

```text
Q = 下整(比率(A, B))
P = 积量(B, Q)
R = 差量(A, P)
```

`R` 即 `A` 除以 `B` 的余数。虽然印刷式压成三行，施法者实际要写比率、下整、积量和差量四枚算子；四次成型各自提供献祭。

## 围绕现实支点旋转坐标

设 `C` 是待旋转坐标，`P` 是支点坐标，`D` 是旋转轴方向，`A` 是角度：

```text
V  = 坐标差(C, P)
V' = 转向(V, D, A)
C' = 移位(P, V')
```

支点、轴和角度均由现实对象或已有计算关系提供。

## 多项异质结构

五项异质数据可以用成对结构逐层分组：

```text
L = 成对(A, B)
R = 成对(C, 成对(D, E))
P = 成对(L, R)
```

之后以取首和取次逐层取得所需项目。规则的多个参数也可以通过补全依次提供。

## 条件重复

设规则 `F` 的第一空缺是递归自身，第二空缺是状态 `S`，并令：

```text
F(Self, S) = 消解(C(S), 接续(A(S), Self(N(S))))
X = 闭合(F)
```

执行 `X(S₀)` 时，只要 `C(S)` 成立，就执行本轮指令 `A(S)` 并到达下一轮状态 `N(S)`；`C(S)` 不成立时，消解关系在本轮结束，下一轮调用不再到达。
