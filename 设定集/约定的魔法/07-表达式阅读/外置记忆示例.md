# 外置记忆示例：空间寄存器

本例说明如何借助现实装置保留并读取一种简单状态。

## 现实装置

准备四个边界明确的现实对象：

- 固定原点标记 `O`；
- 可在直轨上移动的标记 `M`；
- 指明直轨正向的标记 `D`；
- 两个端点间距等于一格的单位构件 `U`。

分别用取实固定这些对象。`M` 与 `O` 实现坐标接口，`D` 实现方向接口；`U` 的两个现实端点给出一格的单位位移关系。

## 读取当前格位

先由单位构件两端的坐标引用构造其长度 `Lᵤ`，再建立：

```text
V  = 坐标差(M, O)
L  = 投影(V, D)
N  = 比率(L, Lᵤ)
```

`N` 描述标记相对原点所占的现实单位数。每次实际使用 `N` 时，整条关系都依据那一刻的装置重新取值。

原点状态可以写成：

```text
判空(坐标差(M, O))
```

这个判定表示当前位置关系是否为默认零位移。

## 改变状态

把一个固定尺度的流动指令引用移动到轨道相应位置并执行，使效果框内标记原子的速度沿轨道改变。导轨和挡块随后通过自然运动把 `M` 限制在下一格。移动多格时，可重新布置或发射指令引用并多次执行；每次实际发生的世界效果分别进入献祭结算。

移动完成后，再次使用 `N` 时会得到 `M` 的新位置。若 `M`、`O`、`D`、单位构件或轨道遭到移动或破坏，读数也会相应改变或成为空值。

这正是外置记忆的边界：被保留下来的是现实物体的状态，引用只负责在使用时重新描述它。
