# 指令参考

## 共通句式

每条基础指令都必须写成一条完整指令句：

```text
定轴符　指令主体　结句符
```

指令句成型后产生引用。基础指令在自己的引用于执行瞬间所在的位置生效。引用可以被拖动、随施法者平移，并受引力或流动影响；接续和消解组成执行关系，各基础指令仍保留自己的位置。

指令主符的[效果框](../../05-世界描述模型/指令效果框.md)决定影响范围和方向；场指令以一枚强度符的尺寸决定状态改变量。主符和强度符的时间轴用于形成完整字形和计算献祭。场效果在执行瞬间完成。

## 现行指令

| 指令 | 主体 | 世界效果 |
| --- | --- | --- |
| [引力](引力.md) | 引力主符、强度符 | 瞬时修改范围内原子与引用的相应状态 |
| [电场](电场.md) | 电场主符、强度符 | 瞬时修改范围内原子的相应状态 |
| [磁场](磁场.md) | 磁场主符、强度符 | 瞬时修改范围内原子的相应状态 |
| [流动](流动.md) | 流动主符、强度符 | 瞬时修改范围内原子与引用的速度状态 |
| [跌落](跌落.md) | 跌落主符及化学结构描述 | 使所描述的单一物质从高维降入世界 |

引力、电场、磁场和流动的主体均为各自主符后接一枚强度符。跌落则在主符后描述所用元素；描述分子时，还要写出每种元素的原子数量。它在化学层级确定物质，未写明的同位素组成、结构细节与初始物理状态由约定按最常见的相容情况补全。

这五种指令构成约定对世界的基础作用方式：四种场指令修改原子物理状态，跌落向世界加入物质。

多条指令通过[接续](../算子/接续.md)与[消解](../算子/消解.md)组成术式。
