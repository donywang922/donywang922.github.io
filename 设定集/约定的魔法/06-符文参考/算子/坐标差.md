# 坐标差

## 输入

“坐标差”组合两个实现坐标接口的引用。对象引用只要具有唯一的坐标意义，就可以直接作为输入。

## 输出

若以 `A` 为第一输入、`B` 为第二输入，“坐标差”产生从 `B` 指向 `A` 的位移引用。

该位移引用同时实现以下接口：

- 方向；
- 长度；
- 主位移。

后续算子可以按照自身的输入要求，直接将同一个结果作为其中任意一种接口使用。

位移沿某一方向的分量可用“投影”取得。

“坐标差”不保存成型时两个输入的位置。结果引用每次实际取值时，都会重新读取 `A` 与 `B` 在该瞬间的坐标，并在最终触发该引用的指令句所规定之坐标方向下，计算从 `B` 指向 `A` 的位移。

第一、第二输入分别位于二输入字形的左位和右位，只有成型瞬间的位置决定参数次序。任一输入缺少坐标接口时成型失败；输入位留空时则依通用规则成为悬置算子，可供封装。
