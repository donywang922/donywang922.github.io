# 闭合

## 类别

“闭合”属于高阶算子，用于为规则引用建立递归自我引用。在计算理论中，这种结构称为不动点。

## 输入条件

闭合接受一个规则引用 `F`。设其签名为：

```text
F : [自身, P₁, …, Pₙ] → R
```

`F` 必须至少具有“自身”这个空缺，而且该空缺必须能够接受签名为 `[P₁, …, Pₙ] → R` 的引用。

## 输出

闭合产生引用 `X`，并建立关系：

```text
X = F(X)
```

如果 `F` 除自我输入外仍有其他空缺，`X` 仍是规则引用，并保留签名 `[P₁, …, Pₙ] → R`。由此可以先闭合递归位置，再在之后补入普通参数。

## 惰性

闭合建立惰性的自我引用关系。实际需要的递归部分在取值时展开，递归状态则由现实状态或引用关系承载。

## 失败

若输入不实现规则接口、规则没有空缺，或第一个空缺不能接受闭合后所得 `X` 的接口与签名，闭合直接失败。

## 用途

闭合用于简洁地书写递归关系；“保留”“分配”和“补全”的组合也可以表达等价关系。
