# 闭合

> 编写状态：名称、语义与接口规则已经确定，符文字形和具体输入位置尚待确定。

## 类别

“闭合”属于高阶算子，用于为规则引用建立递归自我引用。在计算理论中，这种结构称为不动点。

## 输入条件

闭合接受一个规则引用 `F`。设其签名为：

```text
F : [自身, P₁, …, Pₙ] → R
```

`F` 必须至少具有“自身”这个空缺，而且该空缺必须能够接受签名为 `[P₁, …, Pₙ] → R` 的引用。

## 输出

闭合产生引用 `X`，并建立关系：

```text
X = F(X)
```

如果 `F` 除自我输入外仍有其他空缺，`X` 仍是规则引用，并保留签名 `[P₁, …, Pₙ] → R`。由此可以先闭合递归位置，再在之后补入普通参数。

## 惰性

闭合只建立自我引用关系，不会在成型时展开全部递归，也不会保存任何递归中间值。实际需要的递归部分只在取值时展开。

## 失败

若输入不实现规则接口、规则没有空缺，或第一个空缺不能接受闭合后所得 `X` 的接口与签名，闭合直接失败。

## 与计算完备性的关系

闭合使常用递归结构能够简短书写。它不是完备计算性的唯一来源；理论上，同样的递归可以由“恒值”“分配”和“补全”构造，只是表达式会长得多。
