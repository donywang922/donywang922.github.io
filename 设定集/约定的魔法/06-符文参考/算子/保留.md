# 保留

“保留”是二输入基础高阶算子，接受任意引用 `A`、`B`：

```text
保留(A, B) = A
```

所得新引用采用 `A` 的实时取值关系。`A` 的现实状态改变时，结果随之改变；`A` 为空时结果也为空。`B` 参与关系的构成，但其数据内容不进入结果。

结果是一个拥有独立控制位置的新引用。它的数据来源只来自 `A`，但构成历史仍继承 `A`、`B` 以及本次书写，因为两项都参与了该符文的形成。

保留只有在两个输入位均有引用时直接成型。留下输入空缺并封装，可以得到 `K` 型规则；全部留空时签名为 `[引用, 引用] → 引用`。它与分配构成纯计算层的组合完备基础。
