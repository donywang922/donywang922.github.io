## 算子共通规则

普通算子具有固定的一至四个输入位。参数次序由标准输入位置决定；输入排列、悬置、失败、成型、构成历史与献祭的通用规则见[算子与引用](../02-符文基础/算子与引用.md)。

本表共收录三十一个算子。“取实”以现实取样框建立对象引用，“封装”以目标框捕捉悬置算子，其余算子通过既有引用建立新的关系。数量、几何和判定等结果均可沿算子关系追溯到现实来源，详见[数据来源与空值](../03-语言结构/数据来源与空值.md)。
