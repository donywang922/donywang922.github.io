- [数据来源与空值](数据来源与空值.md)：现实来源守恒、主值、默认值与空值传播；
- [引用的取值](引用的取值.md)：关系在何时、依据哪一时刻和哪套坐标求值；
- [判定与确定性求值](判定与确定性求值.md)：判空、逻辑组合与不依赖输入次序的求值；
- [数量、几何与复合数据](数量、几何与复合数据.md)：量、坐标、成对结构与序列的最小操作集；

- [规则引用](规则引用.md)：悬置、封装、补全与高阶规则；
- [术式与控制流](术式与控制流.md)：术式、接续、消解与重复终止；
- [计算完备性](计算完备性.md)：最小组合基础及其表达能力；
- [递归与不动点](递归与不动点.md)：闭合算子如何建立递归。
