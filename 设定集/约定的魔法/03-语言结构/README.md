# 语言结构

> 编写状态：本部分的大纲已经建立，具体语法尚未逐项确认。

本部分将说明约定符文如何组成可以阅读和执行的完整表达。已经确认的最小结构包括：

- 指令句采用“固定开始符—指令主体—固定结束符”的结构；
- 指令句成型后产生引用，而不立即执行；
- 单独的算子符文成型后产生引用；
- 算子可以继续作用于已有引用；
- 引用与算子构成的纯计算层具备完备计算性，但没有自行输出或保存结果的手段；
- 缺少输入但其余部分正确的算子会悬置，而不是失败；
- 悬置算子可以被封装为规则引用，并通过补全逐个取得参数；
- 规则引用能够接收或产生其他规则引用；
- 引用可以指向几乎所有概念，包括抽象值、坐标、方向、角度、常数、生命、灵魂和其他引用；
- 一个概念能否被实际取得，取决于是否存在能够生成对应引用的算子链；
- 实物引用包含对象的一切数据，并能按照对象所支持的不同接口参与操作；
- 一个引用可以同时支持多种接口，而不是只能属于一个互斥类别；
- 任意深度的算子链都不保存中间值，只在引用实际取值时根据当时的世界重新计算；
- 引用随施法者平移但不随其旋转，并且可以由施法者拖动；
- 算子在成型瞬间读取规定输入位置上的引用；
- 施法者身份来自对引用构成历史中献祭的参与，同一个引用可以有多位施法者；
- 法术可以具有分支，也可以包含递归计算；
- 递归通过“闭合”算子建立不动点。
