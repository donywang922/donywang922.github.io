# 递归与不动点

约定将用于建立递归不动点的算子称为“闭合”。

## 自我引用问题

算子在成型以后产生引用，而递归关系需要指向最终形成的引用自身。“闭合”负责在书写完成后接合这两端。

然而，纯计算层需要能够表达递归。约定中因此存在“闭合”算子，用于把规则引用中的自我输入与最终结果接合起来。

## 基本关系

设规则引用 `F` 的签名为：

```text
F : [自身, P₁, …, Pₙ] → R
```

“闭合”把第一个空缺作为自我输入，产生签名为 `[P₁, …, Pₙ] → R` 的引用 `X`，并使二者满足：

```text
X = F(X)
```

这里的等式表示：每当计算关系需要递归调用时，它所使用的第一个参数就是最终形成的引用 `X` 自身。

如果 `F` 在自我输入之后仍有其他空缺，`X` 就是一个保留这些空缺的规则引用。例如，一个以自身和数值 `n` 为参数的规则，闭合后会得到只等待 `n` 的递归规则。有效闭合要求“自身”空缺能够接受这个闭合后的 `X`；也就是说，它必须接受具有剩余签名 `[P₁, …, Pₙ] → R` 的引用。

## 惰性展开

闭合在成型时形成新的引用关系；递归所需的部分在引用被实际取值时展开，并服从纯计算层通常的惰性取值规则。

若取值能够在有限展开后到达终止条件，高维执行机制可以得到相应结果。若被实际需要的递归永不终止，依赖该结果的指令便无法执行。与任何指令都无关的无限递归则不需要取得结果，也不会单独产生世界效果。

## 取值与状态

闭合所得引用在每次取值时，以该瞬间的世界和最终指令句提供的坐标上下文重新计算。跨越取值时刻的状态由现实关系保存。

若 `F` 不实现规则接口、没有任何空缺，或第一个空缺不能接受闭合后所得 `X` 的接口与签名，闭合会直接失败。闭合的完整算子条目参见[闭合](../06-符文参考/算子/闭合.md)。
