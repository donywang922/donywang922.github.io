# 约定的魔法

《约定的魔法》是约定符文体系的通行入门教材。本版既可按章节顺序学习，也可通过符文参考和术语表查阅单项规则。

各章从符文的书写与成型开始，依次讲解引用、算子、指令和执行献祭。重要机制在首次出现时完整说明，后续章节以摘要和链接回引。
